# 赛道二：信任守护师 —— 化妆品内容鉴真与风险识别方案

## 项目简介

本项目面向欧莱雅比赛赛道二「信任守护师」，围绕化妆品相关文案与图片，提供内容真实性识别、风险标注、可信度判断与处置建议。系统能够检测 AI 生成内容、夸大功效宣传、虚假背书、图片篡改线索以及图文一致性风险，并输出可解释的判定依据。

## 赛题理解

本方案将「信任守护师」任务拆解为四个核心能力：

1. **内容鉴真**：识别文案是否存在 AI 生成、夸大功效、虚假背书、违规宣传等风险。
2. **图片鉴伪**：分析图片中是否存在明显篡改、伪造、虚假展示或误导性视觉信息。
3. **图文一致性判断**：判断文案宣称与图片展示内容是否一致，识别「挂羊头卖狗肉」式宣传。
4. **风险分级与处置建议**：输出低、中、高风险等级，并给出平台处置建议与用户提示。

## 运行环境

- Python 3.9 及以上
- 已安装项目依赖，包括 `openai`、`python-dotenv` 等
- 已配置百炼平台 API Key

## 配置方式

在项目根目录创建或编辑 `.env` 文件，写入：

```text
DASHSCOPE_API_KEY=你的API密钥
```

注意不要将 `.env` 文件上传到公开代码仓库。

## 运行方式

### 1. 纯文本鉴真测试

```bash
python test_track2.py
```

该命令会使用默认测试文案，验证 AI 生成检测、夸大功效识别、虚假背书识别、风险等级判断和处置建议输出是否正常。

### 2. 自定义文案鉴真

```bash
python test_track2.py "你的测试文案"
```

### 3. 图文联合鉴真

```bash
python test_track2.py --image "你的测试文案" 图片路径.jpg
```

例如：

```bash
python test_track2.py --image "七天美白三度，七天焕新肌底" test1.jpg
```

## 输出字段说明

系统输出包含以下主要字段：

| 字段 | 说明 |
| ------ |------ |
| ai_generated | 是否疑似 AI 生成内容 |
| exaggerated_claims | 夸大功效或绝对化用语清单 |
| fake_endorsements | 虚假背书或虚假权威引用清单 |
| image_tampering | 图片疑似篡改判断 |
| image_text_consistency | 图文一致性判断 |
| risk_level | 综合风险等级：低、中、高 |
| reasoning | 判定依据与推理过程 |
| suggestions | 处置建议与用户提示 |

## 技术实现

本方案基于通义千问系列模型构建，主要流程包括：

1. **内容风险检测**：对化妆品文案进行 AI 生成、夸大功效、虚假背书等风险识别。
2. **图片内容理解**：对上传产品图片、宣传图或成分表图片进行视觉内容识别。
3. **图文联合推理**：结合文案与图片信息，判断宣传内容是否一致、是否存在误导性展示。
4. **风险分级输出**：根据多项风险信号综合判断整体风险等级。
5. **可解释性输出**：提供推理依据、可疑点清单和处置建议，便于人工复核。

## 适用场景

- 化妆品电商文案审核
- 社交媒体美妆内容风险识别
- 用户举报内容初筛
- 平台内容合规辅助审查
- 消费者内容可信度提示

## 注意事项

1. 本方案输出结果仅用于辅助判断，不能完全替代人工审核或专业法律意见。
2. 模型对图片篡改、成分含量、批准文号等信息的判断存在不确定性，涉及高风险结论时应进一步核实。
3. 涉及法规条款、检测报告、批准文号等内容，建议以官方公开信息为准。
4. 图片分析效果受图片清晰度、文字可见度和拍摄角度影响。
5. 本系统不提供医疗诊断、皮肤病治疗或个体化用药建议。
